# What is an AI agent?

An agent is a model that can **take actions**, not just answer questions.

- It reads a goal, picks a tool, and checks the result
- It keeps going until the goal is met, or it asks you

---

## The agent loop

Every agent repeats four steps: perceive, plan, act and reflect.

- The Planner breaks the goal into small steps
- The Tool Router picks the right tool for each step
- The Memory keeps what worked for next time

> Pause here. Ask who has used an agent this week.

==Land this one:== an agent is only as good as its tools and its checks.

---

## Keeping agents safe

1. Start with *read-only* tools
2. Add actions one at a time, with a person approving each one
3. Log every action so you can review it later
